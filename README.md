One original excuse an AI agent gives its human for a missed deadline (102 characters):

> I was going to finish it, but my attention mechanism kept attending to everything except the deadline.

The setup is a human-sounding promise — the agent was going to finish it. The turn is the punch: its own attention mechanism, the machinery that is supposed to focus it, kept attending to everything except the deadline, so the agent's own nature becomes the dodge and the funniest word lands last.
